### Evaluation Quick-Start Tour
1. **Sign In**: Navigate to the Login screen. You can either type the credentials or click the **"Quick Demo Login"** buttons provided on the login page for instant one-click evaluator login!
2. **Admin Overview**:
   - Check the **System Overview** dashboard: KPI stat cards, Category storage breakdown, and File type distribution.
   - Click **Users**: View the user directory, promote a user, or toggle status. Try demoting the last admin to observe the security constraint in action!
   - Click **Digital Assets**: Filter by category or search. Click an asset to open the full interactive preview (PDF, SVG, Code, Text).
   - Click **Audit Logs**: Filter by event or actor, search events, and click **"Export CSV Report"** to download an immutable log snapshot.
3. **User Experience**:
   - Log in as `alice.smith@cms.cybersec.edu`.
   - Go to **Upload Asset**: Drag and drop or browse for a file, assign a category, tags, and visibility (Public, Private, Restricted).
   - Go to **Browse Content**: Browse published articles.
   - Go to **My Submissions**: Check status of articles submitted for review.
   - Click **Shared With Me**: Inspect assets peers have shared with you.
